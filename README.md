# POS Multi-Store (โปรเจ็คใหม่)

โปรเจ็คนี้แยกจากระบบ POS_Water_Database เดิมทั้งหมด — ไฟล์ใหม่, Google Sheet ใหม่, ไม่แตะไฟล์เก่าใดๆ

**Google Sheet ใหม่:** `POS_MultiStore_Database`
https://docs.google.com/spreadsheets/d/1S2AXBIOSbLNGOUU3kD23H6j-ZP0ttsou8kDkSOkuFcA/edit

## โครงสร้างไฟล์

- `index.html`, `style.css`, `app.js` — หน้าเว็บ (Static Web App, ไม่ต้องมี server)
- `Code.gs` — สคริปต์ฝั่งหลังบ้าน (วางใน Apps Script ของ Google Sheet ใหม่)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

1. เปิด Google Sheet ที่ลิงก์ด้านบน
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างเดิมทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ `Code.gs`
4. ที่แถบด้านบน เลือกฟังก์ชัน `setup` แล้วกด **Run** (ครั้งแรกจะขอสิทธิ์ — กดอนุญาต) ขั้นตอนนี้จะสร้างชีตย่อยทั้งหมดพร้อมข้อมูลตั้งต้น:
   - `Stores` — ร้านค้า (ผู้ชายขายน้ำ, นาแบะโอนลี่)
   - `Users` — ผู้ใช้งาน (จดจำจาก Client ID อัตโนมัติ)
   - `Inventory` — สินค้าของแต่ละร้าน
   - `Couriers` — ผู้จัดส่ง (ไนซ์, เอฟ, เทพ)
   - `Orders_shop_a`, `Orders_shop_b` — ออเดอร์ของแต่ละร้าน **แยกชีตกันคนละแท็บ** ไม่ปนกัน (ถ้าเพิ่มร้านใหม่ในแท็บ Stores ระบบจะสร้างแท็บ `Orders_<store_id>` ให้อัตโนมัติตอนมีออเดอร์แรกเข้ามา)
5. เมนู **Deploy > New deployment**
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL**
6. เปิดไฟล์ `app.js` แก้บรรทัด:
   ```js
   const GAS_URL = 'https://script.google.com/macros/s/PASTE_YOUR_DEPLOYMENT_ID_HERE/exec';
   ```
   วาง URL ที่คัดลอกมาแทนที่
7. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (หรือ deploy ทั้งโฟลเดอร์ขึ้น GitHub Pages / Netlify เพื่อให้ใช้งานได้จากมือถือ)

> ทุกครั้งที่แก้โค้ดใน Apps Script แล้วอยาก deploy URL เดิม ให้ใช้ **Deploy > Manage deployments > แก้ไข (ดินสอ) > Version: New > Deploy** — จะไม่ต้องแก้ GAS_URL ใน app.js ใหม่

## วิธีทำงานของระบบ

**หน้า A — ระบุตัวตน + เลือกร้าน**
เมื่อเปิดเว็บครั้งแรกในเบราว์เซอร์นั้น ระบบจะสร้าง Client ID แบบสุ่มเก็บไว้ใน `localStorage` ของเครื่อง/เบราว์เซอร์นั้น แล้วให้กรอกชื่อครั้งเดียว จากนั้นทุกครั้งที่เปิดใช้งาน ระบบจะจำชื่อ/สิทธิ์ (Permission) ได้อัตโนมัติจาก Client ID โดยไม่ต้องล็อกอินใหม่ ถัดมาเลือกร้านที่จะเข้าไปจัดการ (โลโก้วงกลม + ชื่อร้าน)

**หน้า B — บันทึกออเดอร์**
แสดงสินค้าของร้านที่เลือกเป็นตาราง กดที่สินค้าหรือปุ่ม +/− เพื่อเพิ่ม-ลดจำนวนได้อิสระทีละรายการ มีสรุปรายการ + ยอดรวมด้านล่าง กด **บันทึกส่งออเดอร์** จะเด้ง popup ให้เลือกผู้จัดส่ง (ไนซ์ / เอฟ / เทพ) เมื่อเลือกแล้วออเดอร์จะถูกส่งไปบันทึกในแท็บ `Orders_<store_id>` ของร้านนั้นๆ ทันที (เช่นออเดอร์ร้านผู้ชายขายน้ำเข้า `Orders_shop_a` ส่วนนาแบะโอนลี่เข้า `Orders_shop_b` แยกกันเด็ดขาด)

> ถ้าเคยรัน `setup` เวอร์ชันเก่าไปแล้วและมีแท็บ `Orders` แบบรวมเดียวที่มีข้อมูลอยู่ (ไม่ใช่แค่หัวตาราง) โค้ดใหม่จะไม่ลบแท็บนั้นให้อัตโนมัติ — ให้แยกแถวตาม `store_id` ไปวางในแท็บ `Orders_shop_a` / `Orders_shop_b` เอง แล้วค่อยลบแท็บ `Orders` เดิมทิ้ง

## ติดตั้งเป็นแอป (PWA) บนมือถือ

โปรเจ็คนี้ตั้งค่าให้เป็น PWA (Progressive Web App) แล้ว — เปิดครั้งแรกผ่านเบราว์เซอร์ แล้ว "Add to Home Screen" จะได้ไอคอนบนหน้าจอ เปิดแล้วเต็มจอแบบแอปจริง ไม่มีแถบ URL ของเบราว์เซอร์ให้เห็น:

- **iPhone (Safari):** เปิดเว็บ > กดปุ่ม Share (สี่เหลี่ยมมีลูกศรชี้ขึ้น) > เลื่อนหา **"Add to Home Screen"** > กด Add
- **Android (Chrome):** เปิดเว็บ > จะมีแบนเนอร์ "Install app" เด้งขึ้นมาเอง หรือกดเมนู 3 จุดมุมขวาบน > **"Install app"** / **"Add to Home screen"**

ไฟล์ที่เกี่ยวข้อง: `manifest.json` (ชื่อแอป/ไอคอน/สี), โฟลเดอร์ `icons/` (ไอคอนแอป), `sw.js` (service worker ทำให้เปิดแอปได้เร็วขึ้นและติดตั้งได้ — ไม่ cache การเรียก Google Sheet ข้อมูลออเดอร์ยังสดใหม่เสมอ) ต้องอัพขึ้น GitHub พร้อมกับไฟล์อื่นๆ ทั้งหมดด้วย (รวมทั้งโฟลเดอร์ `icons/`)

## แก้ไข/เพิ่มร้านหรือสินค้า

แก้ไขได้ตรงในแท็บ `Stores` และ `Inventory` ของ Google Sheet ได้เลย ไม่ต้องแก้โค้ด — เว็บจะดึงข้อมูลสดจากชีตทุกครั้งที่เปิดหน้า (ตั้ง `active` เป็น FALSE เพื่อซ่อนแถวโดยไม่ต้องลบ)
